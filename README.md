# multiCam

## General Description

multiCam views and streams multiple cameras: USB/V4L2 cameras, Raspberry Pi cameras (through Picamera2), and network cameras that provide an HTTP or RTSP stream.

It runs as a Duet Web Control (SBC) plugin, or standalone, without DWC, on Linux or Windows. Its web pages show the camera streams, the settings and the log.

# multiCam - 3.7.x branch

View and stream multiple cameras (USB, Raspberry Pi and network cameras) from a Duet Web Control plugin, or standalone on Linux or Windows. This branch is the code for multiCam 1.x, for DWC / DSF 3.6 and 3.7.

The documentation - installation, settings and change notes - is on the main branch, in a folder for each version:

- [multiCam 1.7](https://github.com/stuartofmt/multiCam/tree/main/docs/1.7)
- [multiCam 1.6](https://github.com/stuartofmt/multiCam/tree/main/docs/1.6)
- [All versions](https://github.com/stuartofmt/multiCam#versions)

Building the web interface: the source is in `ui/` and Vite builds it into `plugin3.x.x/dsf/static` (the built files are committed).
